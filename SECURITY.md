# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an email to your security contact/alias at **jason12345@duck.com**. All security vulnerabilities will be promptly addressed.

Please do not report security vulnerabilities through public GitHub issues.
